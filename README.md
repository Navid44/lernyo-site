# lernyo-site

Source of [lernyo.de](https://lernyo.de), the website of **Lernyo**: a learning platform for students in Germany who
prepare for the Abitur or the ZP10. Lernyo was founded in September 2026 by Navid Noorgostar in Frankfurt am Main.

- German pages: [Start](https://lernyo.de/), [Über uns](https://lernyo.de/ueber-uns.html),
  [Impressum](https://lernyo.de/impressum.html), [Datenschutz](https://lernyo.de/datenschutz.html)
- English page: [lernyo.de/en/](https://lernyo.de/en/)

Plain HTML and CSS, served by GitHub Pages. No cookies, no tracking and no external resources: fonts and images are
on this server.

Contact: [info@lernyo.de](mailto:info@lernyo.de)
